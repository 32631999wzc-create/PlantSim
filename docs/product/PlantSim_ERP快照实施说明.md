# PlantSim 企业知识协同 · 离线快照实施说明

版本：2026-10-22 / enterprise-2026-10-22-v1

## 1. 本轮范围

按已确认的园林企业通用ERP业务规划实施。运行时不调用ERP API、物种API、联网搜索或大模型；全部资料、实体、记录、规则和页面内嵌于 plantsim-demo.html。外部原文仅在用户主动点击链接后打开。

沿用已选定的 Clay 设计规范与现有宽屏响应式规则。公开项目不是当前模拟项目，新增企业演示项目有独立编号；没有把公共公告的中标方编造为苗木供应商。

## 2. 页面信息架构

原有项目工作台及八个设计验证步骤保持不变，步骤页脚仍按1—8计数。侧栏追加“企业知识协同”分组：

| 页面 | 职责 | 可用交互 |
| --- | --- | --- |
| 知识与业务查询 | 名称识别、跨快照查询、上下文追问 | 名称消歧、规格选择、范围筛选、来源回看、记录详情、资料引用 |
| 企业资源 | 物料、苗圃库存、报价、养护、成本和公开项目 | 别名/编号检索、批次详情、供苗缺口、供应商跨项目追溯 |
| 本体与知识图谱 | 展示名称—实体—物料—批次—供应商/工单—来源 | 实体切换、关系连线和明细、节点详情、带实体提问 |
| 系统集成 | 展示离线资料包、映射关系、查询日志 | 单快照不可用演练、访问视角演练、资料目录 |

企业查询页不混入项目的线性“下一步”。项目页面通过轻量协同卡进入查询；结果页携带当前选中植物发问。原目标对话中的库存、供应商、报价、别名、工单和ERP问题可转入统一查询。

## 4. 领域对象与检索规则

物种/名称组、规格物料、库存批次、项目、供应商、工单和模拟对象分别建模，使用明确关系连接。

- 三角梅/簕杜鹃/叶子花/九重葛定位贸易名称组；大叶紫与金心双色是不同演示物料，先确认规格再计算缺口。
- 扶桑定位朱槿；名称识别不自动改变原植物清单或模拟参数。
- 红蜘蛛返回叶螨类群与柑橘语境候选，用户确认的是查询范围，不是物种鉴定。
- 腻虫定位蚜虫类群，可返回上海公开排查报道；不将农作物植保资料外推为当前园林现场事实。
- “这种植物”“刚才那家”复用明确的会话实体；没有前文对象时要求补充。更换实体清除旧规格和供应商，更换项目清除会话。
- 未命中问题不生成无出处答案。已知实体但没有库存记录时，不写成库存为零。

离线检索支持列出的查询类型与内置词表，不承诺任意自然语言理解。更新词表、记录或规则后通过重新发布快照生效。

## 5. 业务口径

- 可用库存 = 现存 − 预留 − 隔离。在途始终单列，只有预计日期不晚于项目期限才参与期限内缺口。
- 所有“下月”与交期提示均以2026-10-22快照和演示项目的交付日期解释，不冒充今天的实时结果。
- 报价显示规格、税和运费口径、有效期；已过期报价保留历史标识。
- 预算、已发生、尚未转为实际的承诺、完工预测分别展示，完工预测不能与实际再次累加。
- 公开公告金额不参与现有模拟成本或五维评分。
- 资料引用进入目标草稿，必须经过现有业务Gate确认；只引用名称和来源，不自动修改参数。
- 创建运行时深拷贝当前引用与资料版本；新引用不会修改已有运行。

## 6. 异常与权限演示

系统集成页可演练某快照不可用。查询保留其他可用来源结果，并标识缺项。名称资料不可用时不展示已成功识别的候选结果。

设计师/评审视角用于演示成本明细的显示与隐藏；切换后清除旧答案，避免旧财务答案继续出现在会话中。这是前端演示，不是身份认证或生产权限控制。

## 7. 维护方式

- plantsim-enterprise.js：只读快照、名称映射、实体关系、库存与查询计算。
- plantsim-enterprise-ui.js：页面与交互片段。
- plantsim-enterprise.css：新增页面样式。
- tools/sync-enterprise.cjs：将以上文件同步到原UI、展示样式及离线HTML，保留四个内嵌脚本包。
- plantsim-enterprise.test.js：业务和数据关系测试。
- tools/qa-enterprise.cjs：使用预先启动的本地无界面浏览器进行端到端检查；不会向页面添加服务调用。

```bash
node tools/sync-enterprise.cjs .
node --test *.test.js
```

首次同步后仍需执行现有源码嵌入同步测试。不要直接只改HTML而遗漏维护源码。

## 8. 本阶段完成与后续

本阶段实现可交互快照、公开证据、名称消歧、资源追溯、异常演练与项目引用。后续如补充更多物种、供应记录或真实履约材料，沿相同来源字段扩展；当前没有API接入任务，也没有自动生成、提交采购订单或养护工单。
