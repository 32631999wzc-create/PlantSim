# 登录与工作台批注验收

日期：2026-09-06

- 首次进入展示登录页，可切换企业登录与个人登录。
- 登录后使用左侧竖向导航，导航及页面标题不显示 P0、P1 等开发编号。
- 顶部不再显示“离线交互作品 · DEMO”等解释性文案。
- 工作台采用组织级聚合统计，增加项目、运行、版本、风险、采纳与异常恢复数据。
- 统计卡支持每日、每周、每月趋势切换，趋势详情不显示跨项目名称。
- 企业空间与个人空间使用独立统计口径；个人入口不展示企业归档卡片。
- 工作台不提供清除归档入口，界面以系统数据看板语义呈现。

验证：原有 29 项引擎和业务测试、新增决策测试、登录侧栏与聚合隐私测试全部通过；浏览器已验证登录切换、左侧导航、趋势切换及项目页面。
