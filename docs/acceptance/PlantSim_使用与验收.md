# PlantSim 离线交互作品

最新功能、统计口径与验收见 [本轮业务验收](PlantSim_本轮业务验收.md)。

## 打开与演示

打开 `plantsim-demo.html`。HTML 已内嵌全部样式、业务引擎、数据与交互，不需要安装依赖、启动服务器或连接网络。

- 手动：项目方案 → 导入案例资料 → 处理数量冲突 → 确认基线 → 结构化并保存目标 → 校验冻结任务卡 → 创建并运行模拟。
- 普通运行会显示业务约束弹窗；点击“最小回退并恢复”。“快进”仍运行全部周期和恢复逻辑，不伪造完成状态。
- 结果页可选择 B1/C20/A01，查看入口乔木风险，并通过对话追问原因、替换影响。
- 修改方案创建新版本；新基线需再次确认。在比较页创建同条件重跑，再选择2–3个已完成版本，记录专家采纳。
- 运行记录可切换普通/专家模式、标记 Bad Case、从 Checkpoint 派生独立回放。
- “自动讲解”默认约6分钟，支持暂停、继续和10倍加速。从已有会话重新讲解会先要求确认重置。
- 运行记录右下角点击“完成项目，返回工作台”后，归档保存在本浏览器。刷新或重置仅清空未完成内存，不清除归档；可在工作台“查看成果”。归档页支持导出备份及继续优化。

## 数据与业务边界

- 采用已确认的 Clay 视觉系统；保留20个植物记录、3类蓝图和6条路径，每条默认36个月。
- 文件导入只读取文件名，解析结果来自内置样例；不读取用户文件内容，不上传、不调用真实模型。
- Agent只生成Effect，所有植物状态更新通过StateResolver；路径、版本、运行和回放之间保存独立副本。
- V1/V2/V3的比较值从当前运行聚合，不直接复制规划文件中的示意表。健康与冠幅按路径/植物记录等权平均；高风险按历史中不同植物编号去重，并非按单株数量计数。
- 返工成本为各事项情景风险权重×冻结标准成本后按路径等权平均；权重来自高风险暴露比例与末期根系损伤，并非真实概率。真实成本、物种适生性、碳汇、遮阴覆盖率与雨水效果仍需现场调查和专业模型。
- 目标自然语言解析使用有限规则；结构化字段可人工修订。逐月温度、水分、风速、人流、病害及资源参数影响模拟执行；自然语言说明不等于完整推理。
- 版本比较固定原运行的任务卡、目标、规则版本与seed。更改未来条件的独立运行若签名不同，禁止混入公平比较。

验证边界：交互测试使用当前可用的内嵌 Chromium 浏览器和本地HTTP服务；源码无外部请求/资源。独立安装的Chrome/Edge通过`file://`双击启动未在当前自动化环境实测，不能将本地HTTP测试等同于这项实测。

## 文件组织

- `plantsim-demo.html`：唯一运行时交付文件，可单独复制。
- `plantsim-business.js`：方案预设、建设费用、完成归档与价值统计。
- `plantsim-presentation.js` / `plantsim-presentation.css`：摘要、成本图表与项目完成交互。
- `plantsim-domain.js` / `plantsim-engine.js` / `plantsim-ui.js` / `plantsim-upgrade.js`：便于维护与测试的源文件，HTML不引用它们。
- `plantsim-engine.test.js`：可用Node.js运行的开发回归测试，普通演示不需要Node.js。
- `DESIGN.md`：当前视觉规范；`.design-library`：已安装设计库，无需重新下载。

维护源文件后需同步HTML内嵌代码；回归测试会检查二者一致性。原始需求文档、技术文档和用户修改的页面规划保持不变。
